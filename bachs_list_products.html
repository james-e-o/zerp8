Products

List products

Returns a paginated list of your products, most recent first. Archived products are excluded unless you pass include_archived=true. See Pagination for how to page through results. Requires the products:read scope.

Authorizations

?
Authorization
string
header
required

Bearer token authentication. Pass your API key as Authorization: Bearer sk_.... See Authentication for keys, scopes, and sandbox vs production.

Query Parameters

?
limit
integer
default:20
Required range: 1 <= x <= 100
?
cursor
string
?
include_archived
boolean
default:false

Include archived products in the results. Defaults to false.

Response

Success

pagination
object

Pagination cursors and counts. See the Pagination guide.
